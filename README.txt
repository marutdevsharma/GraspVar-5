# GraspVar-5 Dataset

## Overview
GraspVar-5 is a compact, structured dataset designed for vision-based robotic grasp detection in real-world environments. The dataset emphasizes controlled intra-class variability to improve generalization across variations in object geometry, size, and material properties.

It is particularly suitable for training and evaluating learning-based grasp detection models such as GGCNN and related approaches.

---

## Dataset Summary
- **Total Images:** 450  
- **Object Categories:** 5  
- **Images per Category:** 90  
- **Annotation Type:** 3 Contact Points per object  
- **Data Format:** RGB images + JSON annotations  

---

## Object Categories
The dataset contains the following everyday objects:

1. Plastic Bottle  
2. Puzzle Cube  
3. Tennis Ball  
4. Plastic Ball  
5. Sponge Ball  

Each category includes controlled variations in:
- Shape  
- Size  
- Material properties
